# scan_ip_free_shell

Study about shell script

Script criado para facilitar a localização de IPs disponiveis em redes locais.

Sua utilização é a seguinte:
Informe a faixa de rede desejada. Ex: 192.168.0

informe o IP inicial para consulta > informe o IP final para consulta

Aguarde a verificação. Ao final, o script gerará um arquivo ip_verification_results.txt com os totais de IPs disponiveis e utilizados.
